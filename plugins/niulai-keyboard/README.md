# 牛来
Miucs API v1 独立皮肤，同一包适用于启用 Lua 插件运行库的 macOS / Windows；不覆盖内置 pixel-keyboard。

## 启用 / 热加载
本目录随插件版应用一起分发。macOS 使用 `MIUCS_BUILD_PLUGINS=1 zsh build.sh`，Windows 使用 `./scripts/build-windows.ps1 -Plugins`，然后用 `--plugins` 启动并在可视化菜单选择「牛来」。普通非插件构建不包含此模式。

稳定 ID 为 `niulai-keyboard`。如果曾安装同 ID 用户插件，请备份后移出用户插件目录，避免与内置版本冲突；用户插件不能覆盖内置 ID。
插件开发、用户目录与热加载方式见[插件开发指南](../../docs/plugin-development.md)。宿主负责悬浮锁、拖动、缩放和保存位置，插件不重写这些行为。

## 联动
- 可靠音乐 beat 在两刃间切换，经过中立姿态；无 beat 不凭空造拍。
- 打字 pressesPerSecond 控制有限跳跃频率；完整蓄力、腾空、落地后才能再跳。长按重复不增加输入通道的真实打字速度。
- 键位与双蹄由物理按下/保持/释放控制，与上方运动并行。与像素音乐键盘一致：松键后牛蹄留在最后敲击的键位并抬起，仅新击键移动目标；不会每次回F/J。
- 音频、键盘断开独立处理；输入无活动时保持中立，不是循环 GIF。
- 所有姿态始终向右，不镜像；腾空时延后换刃直到落地。
- 支持源快照比宿主 frame.now 稍晚（最大50ms），避免原呆呆兽版的时序缺陷。

## 当前质量范围
这是一版可测试皮肤：使用12幅刻滑和12幅跳跃实际像素姿态，非整图旋转拉伸。原素材的部分姿态差异仍偏大，不能声称达到高帧率重绘动画；预览为合成输入驱动真实 Lua 场景，不是实际音频检测或原生窗口录屏。
云端执行 Lua 5.4 状态/场景测试。实际 Miucs Skia 渲染、系统权限及双系统验收需原生环境，未在此云端代替验收。

## 0.1.1 尺寸修复
与原像素键盘保持800×460设计画布、80至1600逻辑宽度范围。修复首版最低宽度误设480导致无法缩小到原皮肤大小的问题。宿主按插件ID独立保存窗口大小，切换新皮肤不会自动复制旧皮肤的已保存尺寸；需要在宿主选择相同宽度/比例。
