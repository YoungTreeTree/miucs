# 可视化模块契约 v1

模块同时接收[音频输入契约](../audio-features/README.md)和[键盘输入契约](../keyboard-input/README.md)，通用接口见 `modules/visualizations/api/VisualizationModule.swift`。接口只含数据、生命周期与视口，不携带 AppKit、Combine、Windows UI 或采集对象。

## 注册和生命周期

模块声明稳定 `id`、显示名称、布局元数据和创建新会话的工厂。`VisualizationLayout` 指定基准宽高、最小/最大宽度，均为逻辑点数且必须有限、为正，基准宽度介于上下限之间。默认 400 × 260、宽度 40～1000；`staff-note` 为 800 × 160、宽度 80～1600；`pixel-keyboard` 为 800 × 460、宽度 80～1600。最小宽度均为基准宽度的 10%，并进一步受屏幕可见区域限制。

一次只激活一个会话，每次真正切换均重新创建；选择当前 ID 为无操作，未知 ID 不影响当前会话。启动时未知的已保存 ID 回退铅笔飞鸟。

1. `activate(viewport)`：开始演出。视口是当前窗口的逻辑宽、高与相对该模块基准宽度的缩放；不是物理像素密度。外壳在第一次激活前恢复所属模块的尺寸。
2. `update(input, deltaTime)`：接收最新连续帧、未读事件、区间峰值和秒为单位的时间步长。即使没有新音频也会刷新；模块不能把重复快照当作新帧。
3. `resize(to:)`：接受当前逻辑视口，可在未激活时调用。
4. `deactivate()`：暂停刷新，保留可以恢复的场景；必须幂等。
5. `dispose()`：释放会话资源、订阅与设置界面；必须幂等，之后不再使用。

macOS 在主线程调用这些方法；计算较重的模块可内部调度工作，但发布绘图状态必须保证线程安全。`deltaTime` 是屏幕同步的实际间隔；模块自己控制运动积分步长，避免一次大跳。飞鸟保留原有 100ms 运动上限；五线谱按完整间隔让轨迹过期、只对运动限制积分时间，避免卡帧后补画陈旧历史。

`receive(keyboard:)` 在同一帧的 `update(input:deltaTime:)` 之前调用，提供当前键盘状态及未读事件。此入口默认无操作，五线谱覆盖它暂存快照，在统一更新中推进独立星爆状态；飞鸟沿用默认实现。键盘和音频使用不同的 `sessionID`、序号、权限与重连状态，不能混用游标，也不能因一路不可用跳过另一路。五线谱的音频重连不会重置星爆，键盘失联只取消长按，已有星星自然消失。

`applyAppearance(appearance)` 接收平台无关的 RGB 笔色。外壳在激活新模块前应用当前全局颜色，运行或隐藏期间也可更新；更新只改变绘制，不能清空场景、消费事件或控制音频。带绘制的适配必须实现该入口，无绘制的纯模拟使用默认空实现。渲染器保留自身线宽、透明度和对比衬线；包含笔色的文字缓存应在变化时失效。选色和偏好存储属于外壳，模块不复制取色逻辑或单独保存颜色。

原生窗口切换顺序：保存旧模块位置与尺寸 → 暂停刷新 → 创建新会话、释放旧会话 → 更换原生视图 → 恢复新模块位置与尺寸并传递视口 → 新订阅从当前序号开始 → 激活。首次切换保留旧窗口左上角，再限制到屏幕内。隐藏时切换只更新布局，不激活。

旧快照允许查看，两路旧事件均不补播，音频与键盘连接继续运行。隐藏窗口时暂停绘制，显示时重新订阅两路并激活同一会话。`staff-note` 清理轨迹、星爆和长按节奏，恢复时只接受当前可靠音高与新按下。

## 模块边界

- 模块拥有自己的特征映射、音域、运动、随机场景、粒子和分数。音频层不认识这些对象。
- 连续帧通过 `sessionID + sequence` 去重，用 `frameAge` 检查新鲜度；发生重连要清理旧特征历史。
- 事件数量与显示帧率不同，模块自行决定合并还是逐个表现。飞鸟将同一刷新内的多个起音合为一次振翅，保持动效稳定。
- 原生绘制、颜色界面与持久化适配放在各自 `platforms/<os>/`。macOS 扩展协议返回 `NSView` 与可选设置入口，不污染通用接口。
- 外壳管理窗口、鼠标穿透、刷新和模块菜单。模块不能控制采集、窗口位置或全局重连。

新增模块的具体步骤见 [贡献指南](../../CONTRIBUTING.md)。当前注册指编译进应用的内置模块，不包含动态加载第三方二进制插件。
