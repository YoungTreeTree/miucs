# 可视化模块契约 v1

模块消费 [音频输入契约](../audio-features/README.md)，通用接口见 `modules/visualizations/api/VisualizationModule.swift`。接口只含数据、生命周期与视口，不携带 AppKit、Combine、Windows UI 或采集对象。

## 注册和生命周期

模块声明稳定 `id`、显示名称和创建新会话的工厂。一次只激活一个会话，每次真正切换均重新创建；选择当前 ID 为无操作，未知 ID 不影响当前会话。

1. `activate(viewport)`：开始演出。视口是逻辑宽、高与相对默认画面的缩放，当前默认 400 × 260、scale=1；不是物理像素密度。
2. `update(input, deltaTime)`：接收最新连续帧、未读事件、区间峰值和秒为单位的时间步长。即使没有新音频也会刷新；模块不能把重复快照当作新帧。
3. `resize(to:)`：接受当前逻辑视口，可在未激活时调用。
4. `deactivate()`：暂停刷新，保留可以恢复的场景；必须幂等。
5. `dispose()`：释放会话资源、订阅与设置界面；必须幂等，之后不再使用。

macOS 在主线程调用这些方法；计算较重的模块可内部调度工作，但发布绘图状态必须保证线程安全。`deltaTime` 按屏幕同步时间计算，当前外壳将异常长间隔限制到 100ms；模块仍应控制积分步长，避免一次大跳。

切换顺序：创建新会话 → 旧会话停用并释放 → 新订阅从当前序号开始 → 激活新会话。旧快照允许查看，旧事件不补播。音频连接与代次继续运行。隐藏窗口时暂停，显示时重新订阅并激活同一场景。

## 模块边界

- 模块拥有自己的特征映射、音域、运动、随机场景、粒子和分数。音频层不认识这些对象。
- 连续帧通过 `sessionID + sequence` 去重，用 `frameAge` 检查新鲜度；发生重连要清理旧特征历史。
- 事件数量与显示帧率不同，模块自行决定合并还是逐个表现。飞鸟将同一刷新内的多个起音合为一次振翅，保持动效稳定。
- 原生绘制、颜色界面与持久化适配放在各自 `platforms/<os>/`。macOS 扩展协议返回 `NSView` 与可选设置入口，不污染通用接口。
- 外壳管理窗口、鼠标穿透、刷新和模块菜单。模块不能控制采集、窗口位置或全局重连。

新增模块的具体步骤见 [贡献指南](../../CONTRIBUTING.md)。当前注册指编译进应用的内置模块，不包含动态加载第三方二进制插件。
