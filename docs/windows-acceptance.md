# Windows 验收清单

Windows 实现使用 .NET 8 / WPF、WASAPI 默认多媒体输出设备回环和只读物理键盘监听。跨平台核心测试、Windows 交叉构建与 Windows 桌面实测是**三种不同证据**：Linux 构建出 `.exe` 不代表已在 Windows 运行。本清单的原生项目在 dot Linux 开发环境中均为 **未执行，等待 Windows 实机**，不得改写为通过。构建与自动测试的具体结果以本次交付验证报告为准。

## 无需 Windows 的自动检查

从仓库根目录运行：

```sh
dotnet run --project tests/platforms/windows/CoreTests/Miucs.CoreTests.csproj -c Release
dotnet build apps/windows/Miucs.Windows.csproj -c Release
```

核心测试使用合成 PCM、事件与临时偏好文件，不采集声音、按键、屏幕，也不改变真实偏好。窗口放置测试覆盖不同长宽比、小屏、负坐标、断开显示器后的越界恢复与损坏偏好，但不能代替 Windows 混合 DPI 实测。
