# 验证记录

当前内置插件为奶牛猫、麦芬、牛来、平次与和叶。已移除插件的专属绘制和性能报告已清理；历史版本可从 Git 历史追溯。旧报告中的通过数和性能值只代表对应版本，不应当作当前构建的验收结论。

## 当前检查入口

- [插件回归说明](../../tests/plugins/README.md)：奶牛猫固定参考回放、其他皮肤规则、隔离传输、资源释放与热重载。
- [贡献指南](../../CONTRIBUTING.md)：音频、键盘、窗口、外观及双平台构建命令。
- [插件运行时](../plugin-migration.md)：Lua/Skia 架构、资源限制和平台验证。
- [Windows 实机验收](../windows-acceptance.md)：设备、DPI、输入权限、长时间运行范围。
- [四个插件的 GIF 清单](../assets/plugins/manifest.json)：统一合成输入导出的预览数据。

本目录保留共享音频、键盘、宿主和当前皮肤的历史验证数据。测试数量不可跨版本相加；GIF 导出帧率不代表真实窗口刷新率，短时测试不能替代持续内存、GPU 和跨屏实机验证。
