# 犬夜叉 · 无对白动作皮肤

用户选定「坐下！」喜剧方向，并要求画面移除所有对白文字，只用动作表达。最终效果以[实际运行预览](runtime-preview.gif)为准；`concept-v1.png` 仅保存最初造型参考，其中对白已被后续要求取代。

## 输入和时序

新键盘按下触发 0.60 秒逞强：3 → 4 → 5 → 16 → 1。只保留一个有效期 160ms 的近期后续动作；重复键、输入摘要不会触发动作。

音乐联动从第一枚合格拍点启动，随后每四枚合格拍点尝试启动；要求置信度至少 0.6、强度至少 0.35、50–200 BPM 且事件新鲜。动作未完成时丢弃触发，不排队。

| 联动时间 | 犬夜叉 | 戈薇 | 七宝/尘土 |
| --- | --- | --- | --- |
| 0.00–0.20s | 站姿、转头 | 抬手准备 | 七宝观察 |
| 0.20–0.48s | 念珠拉下，伸手扑落 | 食指前伸向地面 | 七宝瞪大眼睛 |
| 0.48–0.62s | 落地、压低、双脚落下 | 指地最强姿势 | 七宝惊起；尘土从后景扩散 |
| 0.62–1.20s | 趴伏、抬眼 | 保持后收手 | 躲藏、探头、偷笑；尘土 0.84s 消散 |
| 1.20–1.94s | 双手撑起 → 跪起 → 站起 | 放下手回待机 | 七宝回待机 |

声音中断后已开始的动作播完；键盘断连只清除键盘驱动的逞强。长于 0.5 秒的更新间隔、隐藏重新激活会清除动作，避免恢复后补播。待机仅使用绘制的眨眼帧。

## 实现与检查

保持 800×460 画布、原有五行键位与按键事件映射。角色、石头和尘土保持固定世界锚点，所有帧使用统一像素比例；背景等比裁切。无台词气泡，只有真实键帽标签。

- `tools/plugins/register_inuyasha_frames.py`：读取 alpha 定位透明间隔与落脚点，保存原始像素。
- `tests/plugins/inuyasha_replay.py`：在生产 Lua worker 上检查全部 40 帧、动作同步、输入有效性、生命周期、尺寸与锚点。
- `tools/plugins/inuyasha_preview.py`：合成输入驱动实际渲染器，输出 12 秒 GIF、透明 WebP 和双倍尺寸关键画面。

此预览展示真实插件渲染路径，不代表真实音乐拍点质量或 Windows 桌面实测。
