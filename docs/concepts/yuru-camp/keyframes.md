# 摇曳露营 · 关键帧设计

依据确认的第一版概念图，保持上方横屏和下方五行键盘。所有角色动作由 imagegen 绘制，代码负责输入判定和选帧；不通过程序变形、旋转或平移整个人物伪造动作。

| 图集 | 帧 | 关键动作 | 驱动 |
| --- | --- | --- | --- |
| 抚子吃面 | 1–3 | 捧杯静止、筷子探入、挑起面条 | 新按键启动 |
| | 4–7 | 面条靠近嘴、张嘴、吸面、收掉最后一小段 | 同一段动画继续 |
| | 8–12 | 闭嘴咀嚼、满足地眯眼、放低筷子、回到捧杯 | 不被新按键打断 |
| 凛喝茶 | 1–4 | 捧杯、看杯子、缓慢举杯、杯沿靠近嘴 | 首拍及之后每四拍；只在上一动作完成后启动 |
| | 5–8 | 轻啜、短暂保持、放低一点、满足地呼气 | 保持慢节奏 |
| | 9–12 | 杯子回胸前、睁眼、放松、回到静止 | 不循环补拍 |
| 篝火 | 1–8 | 小火、聚拢、升高、峰值、右卷、左卷、回落、小火 | 每个可靠音乐拍点 |
| 左右手套 | 各 1–4 | 悬停、弯曲、压下、回弹 | 真实键位状态 |

共 40 个绘制帧。抚子约 1.05 秒一口面，凛约 1.6 秒一口茶；密集按键最多保留一个仍在有效期内的后续动作。篝火小幅跳动，静音后保留低火静帧。

椅脚、火盆脚与手套袖口作为固定锚点。保留生成的透明 PNG，通过 sourceRect 与注册偏移读取原像素，统一像素缩放；不对不同帧拉伸。角色头部、帽子和椅子都留在显示区内。

键盘沿用真实五行键位、双手跟随与多键反馈；深蓝框、奶油键帽、暖杏色压键、珊瑚色格纹包角。键盘和音频分别处理权限、会话、去重、断连和过期数据；隐藏恢复或卡顿不补播。
