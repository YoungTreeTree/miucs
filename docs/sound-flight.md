# 铅笔音乐飞鸟：实现与验收

更新：2026-10-23。

## 使用

`zsh build.sh` 构建 `dist/Miucs.app`。默认打开 400 × 260 透明悬浮画面，鼠标穿透、不接受键盘焦点。菜单栏波形图标可显示、隐藏、重新连接声音，或切换「调整位置与大小… / 完成调整（恢复鼠标穿透）」。菜单栏「画面大小」提供 80%、100%、125%、150%、200% 预设；调整模式下也可拖动右下角连续缩放。始终保持 400:260 比例，宽度限定在 280～1000 点且不超出当前屏幕，大小与位置使用明确的坐标和尺寸记录保存，移动后自动更新，窗口关闭或应用退出时补存；下次启动优先恢复该记录，兼容旧版窗口自动保存数据。恢复过程不会用初始默认位置覆盖记录，显示器移除时会把画面限制到当前可见屏幕。隐藏时退出调整模式并停止绘制定时器。

画面使用原生 AppKit 路径绘制，石墨灰主线、极细浅色衬线，无底色、卡片或窗口阴影。云、地面、鸟、管道和提示统一为线稿，数字使用系统手写字体。笔迹扰动按物体 ID 固定，不在每帧重采样。动画以 60 fps 更新。可靠音高到达时立即设置运动目标，下一帧开始升降；无声且运动已收稳时跳过重复绘制。管口笔迹种子只取自物体 ID 与上下位置，不随开口高度变化。

## 音频与表现

| 输入 | 表现 |
| --- | --- |
| 主旋律音高 | 即时设置鸟的目标高度，短缓动跟随；近处管道提前移动并柔和展开开口 |
| 起音事件 | 一次振翅和一笔羽毛尾迹；管道独立随机生成 |
| 音量包络 | 翼幅与身体伸展幅度，不改变高度 |
| 低频能量 | 管道线条粗细和管口回弹，始终留在保留的碰撞包络内 |
| 中频能量 | 前进速度在活动基速附近变化 |
| 高频能量 | 细短尾迹数量 |
| 频谱重心 | 背景线条轻重，采用约 1.2 秒平滑 |
| 频谱平坦度 | 尾迹分散程度 |
| 静音 / 数据超时 | 停止写入管道、收翅、逐渐减速至精确停止 |

`AudioEngine.features` 发布原有基础测量；新增 `AudioEngine.melody` 发布 `MelodyFrame(time, pitchHz?, confidence, isMelodic)`。主旋律没有用频谱重心、最大 FFT 频点或音量代替。

鸟后方随鸟一起升降的手写标签显示当前可靠主旋律的绝对音名与八度：C4 为中央 C，A4 为 440 Hz，升半音用 ♯ 表示。标签直接来自音高估计，不从鸟的缓动位置反算，因此不会被自动音域适配改变音名。它表示最近的十二平均律音符，不推断歌曲调性或相对唱名。音符边界采用 15 音分滞回避免颤音时频繁闪换；短暂未检出时保留并淡出，240 ms 后显示淡色「—」，静音或断开立即隐藏旧音名。

## 音频自动恢复

采集连接与应用的监听意图分开管理。休眠或屏幕关闭时停止当前流并取消重试，唤醒后等待约 0.7 秒重新查询显示器、建立新流。输出设备切换、显示器变化和用户会话恢复也会触发重建；短时间重复通知合并处理。

采集错误会按 1、2、4、8、16、30 秒逐步延长间隔自动重试，之后最多每 30 秒一次；持续收到正常数据 20 秒后恢复短间隔。每两秒检查一次数据健康度：默认输出设备正在运行且超过 12 秒没有有效音频数据时自动重建。静音 PCM 仍算正常数据，输出设备空闲时不以无数据判定故障。连续八次解码或分析失败也会重连。

每次连接拥有独立标识和分析器，旧流的迟到数据、错误或启动完成都不能覆盖新连接。主动停止或退出会取消重试并移除观察者；macOS 捕获控件中的主动停止也会得到保留。授权不足时仅定期检查授权状态，授权恢复后自动连接，不反复请求捕获。菜单栏保留「重新连接音频」手动入口。

恢复测试使用可注入采集器和真实异步重试任务，覆盖中断、退避、休眠/唤醒通知、设备变化合并、静音与数据卡死、授权恢复以及旧连接竞态。另用真实 ScreenCaptureKit 流验证内部休眠/唤醒与配置重建后继续交付音频；测试没有让电脑实际休眠或切换物理设备，报告仅存检查结果。

## 主旋律提取及明确限制

新增纯 Swift / Accelerate 的因果近似提取器，4096 点 Hann 窗、1024 样本步长。输入保留各声道功率，反相不抵消。对插值后的谱峰做 10 音分分辨率的谐波显著性投票、子谐波抑制与短时轮廓连续性选择；可靠音高直接发布，不额外等待第二帧确认大跳；候选选择仍保留短时连续性约束。支持范围约 E2…C7；静音跳过 FFT。

这不是完整的 MELODIA 实现，也不是训练好的音乐理解模型。`confidence` 是启发式置信指标，不是校准概率。它倾向于选择显著、连续的谐波主线，但无法保证在所有复音音乐中选择人耳认为的主旋律；强伴奏、复杂歌剧和密集编曲可能误选。人声合成测试不等于真实歌唱验证，因此另外跑了 ADC2004 的真实/合成标注片段，逐曲结果完整保留。

高度采用半音坐标，初始 C3…C6。最近 30 秒有效音高的 10%/90% 分位各外扩 2 半音，音域跨度至少一个八度；有至少 3 秒、24 个有效样本后开始适配，边界每秒最多移动 0.7 半音。可用飞行区上下各留出约 15% 安全空间。音高缺失时保持最后高度，首次无音高为中间高度。音高输入到达后直接设置目标高度；使用保持速度连续的临界阻尼运动收稳，不做路径预写或回放。

## 即时飞行与管道避让

已移除原先在前方写路线、鸟延后经过的机制，因此不再有随场景滚动产生的约 2～3 秒等待。当前可靠旋律立即设置鸟的目标高度，下一动画帧开始运动。临界阻尼缓动不跳位置、不弹跳：从静止切换音高时，150 ms 内完成超过 95% 的高度变化；小幅音高抖动也会被自然过滤。鸟身倾角随实际升降速度平滑改变。管道不会反过来限制鸟的高度。

管道在鸟前方 280 单位随机生成，中心在 72～180，开口半高 40～48。有声音时每前进 74～90 单位产生一根（动画离散步长可多出约 1 单位），替代此前至少 112 单位且必须等待起音的条件；持续音也有管道。普通启动每次使用新随机种子，验证与预览使用固定种子。

距离鸟 220 单位以内，管道就开始以较慢的临界阻尼运动提前避让；使用鸟的当前运动趋势做约 45 ms 外推，90 单位内完全进入保护状态。管口用圆滑的安全包络，覆盖鸟体上下各 14 单位余量：大跳音时开口柔和展开，随后收回正常宽度，不再瞬间硬移开口。保护持续到管道整个宽度越过鸟嘴、尾巴，之后逐渐释放追随。鸟与管道在同一动画子步更新，因此整个过程中都保持可穿行；输入到达本身不会让鸟或管道瞬移。远处管道保持生成时的高度，每根只加一分。笔触误差仍固定在物体上，管道移动不会重新随机生成笔迹。管道整层（含浅色衬线和排线）按水平位置从画面右缘的完整可见度渐变到鸟所在竖线的零可见度；到鸟处及其左侧不再绘制。

48 kHz 下旋律窗口覆盖约 85 ms，输出间隔约 21 ms。用每次 10 ms 的 PCM 块输入，测量音符切换到第一帧正确新音高可用的时间，三个受控跳进分别为 70 / 50 / 50 ms，原实现为 200 / 160 / 160 ms。这是基于样本交付时刻的分析响应测试，包含窗口与步长等待，不包含实际计算耗时、系统音频采集、主线程调度、显示刷新与新增的短运动缓动；尚未测量真实声画端到端延迟，不能称为物理零延迟。

## 铅笔配色

菜单栏「调色盘…」打开独立原生窗口，提供原生石墨、森林来信、海盐微风、日落橘子、紫色梦境、月光粉笔六套预设。小鸟（含眼睛）、管道、音符与文字、云朵与地面、飞行尾迹使用独立的 sRGB 笔色；系统调色盘、HEX 输入与快捷色卡均可修改，也支持整幅同色。浅色衬线仍保留以增强桌面上的辨识度。

`PencilPaletteStore` 将配色写入独立的版本化 UserDefaults 键，重启时加载，无效数据回退为石墨。配色变化通过 Combine 同步到已有绘制视图，不重建飞行场景；仅在颜色变化时更新 CGColor 和文字缓存，笔迹路径缓存继续复用。关闭调色窗口不影响桌面窗口的位置、大小或鼠标穿透。

调色预览使用固定合成场景与生产绘制器，切换浅纸、深色、透明棋盘只改变预览底色。`zsh scripts/test-palette.sh` 使用隔离偏好设置验证保存恢复、无效值处理、分部改色、实际像素变化和透明背景，并导出窗口及配色预览至 `build/palette-preview/`。

## 绘制性能

动画改为 macOS 14 的视图级 `CADisplayLink`，按当前屏幕刷新回调推进，目标 60 fps，使用显示时间戳计算运动步长。去掉定时器到主线程异步任务的额外跳转，重复显示不会建立多个刷新源；隐藏或移出窗口时停止，重新显示时恢复。

绘制使用 Core Graphics 路径，笔迹按种子和局部形状复用，平移不重新生成路径。缓存只保存每个种子的当前形状，上限 512 项；文字复用 Core Text 排版，上限 64 项，分数增长不会无限占用内存。浅色衬线、手写字、透明底与音高响应均保留。

管道仍按右侧到鸟位置的同一渐变消失，但只在每根管道的 60 单位窄区域做透明合成。管道彼此不重叠，窄区域包含线宽和笔触扰动余量，避免每帧合成整个右侧区域。

性能探针使用固定种子的合成场景，分别记录 400、800、1000 点宽、2 倍像素密度下的离屏绘制；另显示真实原生透明窗口，预热一秒后测六秒。原生窗口记录的是主线程绘制提交时间与绘制间隔，不包括 GPU 合成完成时间；离屏与原生结果均受机器负载影响，不代表所有歌曲与桌面的帧率保证。对比记录保留全部尺寸和测量边界：[性能记录](validation/render-performance.json)。合成静帧重复绘制保持一致，前后画面比较使用预乘 RGBA，透明像素不会造成虚假差异。

本机 1000 点原生窗口的平均绘制提交时间约从 0.78 ms 降至 0.51 ms，绘制间隔的第 95 百分位从约 18.64 ms 降至 16.83 ms；恢复显示后的一秒记录到 60 帧。离屏结果中，400 点未见改善、800 点接近持平、1000 点平均绘制耗时降低约 27%，因此只将大尺寸绘制与原生提交开销的下降作为本轮测量结论。

```sh
zsh scripts/measure-performance.sh
zsh scripts/measure-performance.sh --cadence
```

后一个命令短暂显示合成测试窗口，验证隐藏停止、再次显示恢复。探针不读取真实屏幕或系统声音，不改动用户保存的位置和大小。

## 复现与调试

```sh
zsh scripts/test-melody.sh
zsh scripts/test-flight.sh
zsh scripts/test-audio-recovery.sh
zsh scripts/validate-audio.sh
zsh build.sh
dist/Miucs.app/Contents/MacOS/Miucs --verify-flight-window --output "$PWD/docs/validation/flight-window-tests.json"
dist/Miucs.app/Contents/MacOS/Miucs --render-flight-preview --output "$PWD/build/flight-previews"
```

实际播放验证会短暂播放低幅度测试音：

```sh
zsh scripts/validate-audio.sh --live
```

播放声音时，可验证真实采集流恢复（只记录通过/失败，不保存声音特征）：

```sh
dist/Miucs.app/Contents/MacOS/Miucs --verify-audio-recovery --output "$PWD/docs/validation/audio-recovery-system.json"
```

若本地已有 ADC2004 WAV/REF 文件：

```sh
python3 scripts/evaluate-melody.py build/adc2004
```

预览命令明确使用合成的音频特征，只用于绘图验证；普通应用启动始终读取系统音频。应用不保存真实 PCM、屏幕画面或任何语音内容。运行时没有网络调用、外部模型或 Python 依赖。

参考：[谐波显著性定义](https://essentia.upf.edu/reference/std_PitchSalienceFunction.html)、[主旋律提取背景](https://www.justinsalamon.com/melody-extraction.html)、[ADC2004 数据来源](https://www.ee.columbia.edu/~dpwe/LabROSA/projects/melody/)。
