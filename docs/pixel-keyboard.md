# 像素音乐键盘

第三个内置模式：横向五线谱显示屏、逐键绘制的像素键盘、左右黑猫白手套猫爪。屏幕最左边放置根据用户照片转制的透明像素猫头，保留黄绿色眼睛和白下巴；头像占 64×64 点，右侧谱面为 640×128 点，保持原来的 5:1 比例。画布 800×460，宽度 600～1600，保持比例并服从屏幕可用范围。使用现有悬停锁、拖动、缩放及各模块独立位置保存。

## 音乐与按键

- 屏幕内复用第二种 UI，保留真实谱位、音名、旋律轨迹、音量缩放、符干倾摆、键盘星爆与节拍轻弧；屏幕外沿裁切，不改变音高识别。
- 键盘覆盖 ANSI 主键区五行，按物理键码映射，不依赖输入法。键帽显示固定布局名，macOS 底行用 Fn/Ctrl/Opt/Cmd，Windows 用 Ctrl/Win/Alt。功能键、方向键、导航区、小键盘首版不显示。
- 左右分区按键各驱动一只爪；同一帧多键同时按下全部显示压下状态，每只爪落向该侧最近一次按下的键，空格两爪交替。小爪允许遮挡键帽下半部。
- 下压键帽变为珊瑚色并下沉 4 点。爪子短距离移动、下压与回弹，不保存移动队列；快打直接追随最新位置。短敲至少保留 120ms 的视觉反馈，长按保持，忽略系统重复事件，松开停止保持。修饰键左右区分，Caps Lock 每次切换短暂反馈。
- 音乐和键盘权限独立。音频静音、断开、重连不重置爪子。停止监听、安全输入、隐藏和切换清掉按压；恢复仅响应新按下，不补播旧按键。过期事件、丢失释放事件与长帧都不会造成卡键或积压动画。
- 屏幕跟随全局笔色；硬件固定为奶白/灰紫，猫爪固定黑白。无新增采集源、逐键计时器或文字记录。

## 实现与验证

静态硬件与键帽/猫爪绘制内容预缓存。macOS 由现有屏幕刷新更新图层，爪子静止且音乐无变化时不提交无意义更新。Windows 使用冻结的 DrawingGroup 缓存硬件与猫爪，嵌入原有 WPF 五线谱绘制。

运行 `zsh scripts/test-pixel-keyboard.sh`：检查布局、多键、长按/释放、修饰键、空格交替、过期/未知/重复事件、代次与生命周期；原生测试检查音乐和键盘并行、音频失联、三个尺寸、五种笔色与浅深背景，并生成合成 PNG/GIF。Windows `scripts/test-windows.sh` 包含对应状态测试和编译，WPF 原生 smoke 在 Windows runner 上运行。

合成演示直接喂入音频特征与物理键位事件，不代表真实音高识别评测，也不记录用户输入。当前机器只能执行 macOS 实机验证；Windows 原生效果仍须 Windows 实机或 CI 验收。
