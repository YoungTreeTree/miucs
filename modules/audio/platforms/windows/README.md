# Windows 音频实现

- `Capture/`：原生 COM WASAPI 共享模式回环，采集默认多媒体播放设备，不打开麦克风。专用后台线程解码并分析，再发布到内存通道；没有录音保存或网络上传。
- `Core/`：C# 原生 FFT、特征/旋律/节拍分析及有界事件通道。独立于 Windows UI，可运行合成验证。

实际 mix format 支持 PCM16/24/32 及 Float32（含 WAVEFORMATEXTENSIBLE），保留实际采样率（8～192kHz）。超过两声道时按声道掩码混成分析用的立体声，不再要求把播放设备改成立体声。采样率在分析前对齐到 48 kHz，与 macOS 固定采集率一致。回环缓冲使用设备最小周期，不再固定等待 100 毫秒。非有限样本归零，浮点超出 ±1 的有效幅值不截断。

每秒在采集后台确认默认设备，设备切换或失效时重新打开并换代；错误以 1～30 秒退避恢复。停止、休眠、重连和 WASAPI 不连续包清空旧代次与分析历史。权限拒绝单独报告。停止等待后台退出最多 250ms；如果驱动调用阻塞，旧线程保留自身清理责任，但生命周期/代次隔离禁止它覆盖新状态或发布旧数据。正常空闲端点可能没有 PCM 包，不伪造静音帧，也不会因静音循环重连；新鲜度由消费端判断。

构建、启动、测试及真实平台验收见 [应用说明](../../../../apps/windows/README.md)。Linux 合成测试与交叉编译不等于已通过 Windows 回环、设备热拔插或休眠实测。
