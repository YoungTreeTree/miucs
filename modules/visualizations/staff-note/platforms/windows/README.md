# 五线谱音符 · Windows 绘制适配（规划）

Windows 当前没有应用或绘制实现，不限定语言与 UI 框架。请先阅读
[通用可视化接口](../../../../../contracts/visualization/README.md)与
[Windows 应用入口](../../../../../apps/windows/README.md)。

本目录负责把 `staff-note` 的场景画成透明、鼠标穿透的原生画面，不负责采集或分析音频。
参照 `../../core` 的映射与生命周期，以进程内消息消费通用音频特征；不可依赖 macOS 文件。

- 模块标识 `staff-note`，名称「五线谱音符」，基准 800 × 160，宽度 600～1600 点，并受屏幕可用区域限制。
- 固定高音谱号，B4 位于 y=74，五条线 y=58/66/74/82/90，间距 8 点；E2～C7 保留真实谱位及加线，半音统一用升号。
- 实心符头中心固定 x=640，八分音符造型；音高平滑收稳约 150 ms，起音触发符干和符尾绕符头中心左右倾摆，每侧限 20°，回摆周期约半秒，连续起音交替施力。`swayAngle` 单位为弧度；符头、升号、加线和音名不随倾摆旋转。
- 体积缩放围绕符头中心，按当前乐段的短时分贝范围增强对比，约 0.8～1.5 倍，静音回到 0.94 倍；参考 `StaffVolumeTracker` 的 3 秒范围收敛和最小 12dB 动态跨度。
- 轨迹只记录可靠真实谱位，最多 512 点、8 秒；失去旋律时留在最后高度、音名淡为 `—`；静音停止新倾摆，已有角度平滑回正。
- 重新连接、格式变化、隐藏恢复及模块切换不得补播旧事件或轨迹。
- 接收公共 `VisualizationAppearance` 笔色，默认石墨灰；保留浅色衬线与固定笔迹扰动。选色由应用外壳统一提供，不另做模块调色窗口。

验收应复用合成特征样本，并覆盖真实谱位、加线、缩放、深浅背景、稳定笔迹、原生刷新及独立窗口状态。
不要放置假实现或声称 Windows 已受支持。
