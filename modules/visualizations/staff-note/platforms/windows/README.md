# 五线谱音符 · Windows

C# 纯数据 `StaffNoteScene` 与 WPF `StaffNoteView`，由 Windows 应用外壳组合，且不引用 macOS、采集器或窗口。

- 800 × 160 逻辑坐标；宽度 80～1600，由外壳进一步限制到显示器工作区。
- 固定谱位：B4=74，五线 y=58/66/74/82/90，G2～C6 跟随，不转调、不画额外加线。
- 可信主旋律门槛 0.48；15 音分迟滞，大跳由不同 PCM 时间的 100/125/150ms 持续观测确认。
- 约 150ms 收稳；响度按 3 秒动态范围映射到 0.8～1.5；符头固定，只有符干/符尾绕其倾摆，最大 20°。
- 轨迹有界 512 点 / 8 秒；旋律缺失不延长，静音/采集失联分段，代次和格式改变清空。绘制与 macOS 对齐：统一路径和渐变淡出，符头前 10 单位平滑衔接，重接缺口的曲线从两端伸展后合成连续路径；补线计时从结果到达时开始。
- 拍点与 macOS 共用相同规则：落点 x=112～712、y=48～112，相邻落点横向至少间隔 120；两层主波相隔 90ms，三道小弧分别延迟 100/155/210ms，最多 4 拍 / 20 弧 / 890ms。完整 800×160 画布允许水花越过五线谱，上下各 8 点渐隐；三档弧端透明度、浅色衬线和纵向 0.9 倍压缩与 macOS 一致。路径缓存复用。
- `KeyboardStars` 将 Windows set-1 物理扫描码（扩展键 OR 0x100）映射为 ANSI 主区。普通键初次按下生成星爆，300ms 后每 180ms 小星爆，忽略系统连发；修饰键仅按下，Caps Lock 每次切换。
- 最多 16 次星爆 / 112 颗星；独立于音频，键盘失联取消长按但已有星星自然消失。切换/隐藏清空，恢复不补播。
- 全局笔色只改变绘制缓存，不改变场景或输入。所有输入仅在内存使用，不保存按键或文本。

`tests/platforms/windows/CoreTests/VisualizationTests.cs` 使用合成特征/按键验证纯场景。WPF 原生渲染、深浅背景、DPI 和真实刷新仍需 Windows 上按应用 README 验证；Linux 核心测试不代表原生 UI 验收。
