# Windows 铅笔飞鸟绘制入口 · 规划中

本目录预留原生绘制与配色界面适配，尚无 Windows 视图或绘图后端，不预先指定语言、窗口工具箱或图形 API。

场景规则在 `../../core/`，包括音高高度、带宽距离、音量体积、气团、管道避让与粒子。后续可以复用可用的通用实现，或在其他语言中按 [模块契约](../../../../../contracts/visualization/README.md) 和测试样本实现等价会话。此目录依赖通用场景与契约，不引用 `platforms/macos/`。

适配职责：将场景状态画成稳定铅笔线条，维持透明留白、细浅衬线、管道右到左渐隐，提供原生笔色转换与设置面板。窗口、穿透、位置持久化和刷新调度由 `apps/windows/` 负责。

验收包括浅/深背景、不同缩放、静态画面无笔迹闪烁、音高/响度/带宽映射、平滑避让安全余量、短起音与气团峰值保留、模块停用后无残留资源。可使用合成音频与 `PencilFlightSampleScene` 对照；禁止为公开示例捕获个人桌面或真实播放内容。平台测试放到 `tests/platforms/windows/`。
