# 铅笔飞鸟 · Windows

C# `FlightScene` 根据公共音频契约计算场景，WPF `PencilFlightView` 负责透明矢量铅笔绘制，不依赖 macOS、采集器或窗口。

- 基准 400 × 260，宽度 40～1000；音高以 MIDI 半音映射到高度，最近 30 秒可信旋律缓慢调整音域。
- 主旋律驱动阻尼弹簧，音量改变大小/翼幅，起音触发振翅，频谱带宽决定下一根管道的距离，变化峰值生成气团。
- 管道提前平滑避让；接近小鸟时柔和扩大缺口，右到左渐隐。管道数、粒子和气团均有上限。
- 静音停止生成管道，减速并收翅；400ms 陈旧帧按失联处理，240ms 无新有效旋律不再显示音名。
- 公共颜色更新只清理绘图缓存，位置/尺寸/刷新/鼠标穿透由外壳统一管理。

移植使用确定性纯数据场景，Windows 绘制采用稳定手工路径而不是逐帧随机扰动。画风为独立 WPF 实现，并非 macOS 像素级复刻。运行纯场景测试：见 `apps/windows/README.md`。WPF 实际显示、DPI/多屏与性能需要 Windows 实机验收。
