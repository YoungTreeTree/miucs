# Windows 键盘输入

`KeyboardCapture` 使用专用消息线程上的 `WH_KEYBOARD_LL` 只读监听；始终调用后续钩子，不拦截、注入、转换或记录输入文字。默认关闭，由托盘菜单显式开启，偏好仅保存开关。

`KeyCode` 为 PC/AT Set 1 物理扫描码；扩展键置 `0x100`，例如 A=`0x1E`、左 Control=`0x1D`、右 Control=`0x11D`。布局不取决于输入法。Shift/Control/Alt/Windows/Caps Lock 分别映射到公共修饰标志；硬件 Fn 没有通用 Windows 扫描码，不伪造。

事件只在内存保留最多 128 个/250ms，频率最多 256 次/1s。普通 OS 自动重复被归为 `Repeated`，不增加真实敲击频率；两侧修饰键分别跟踪，Caps Lock 仅每次切换投递一次。订阅者独立，新订阅不补播，代次变化清空长按和历史。`Core/` 可在 Linux 上单独测试。

窗口外壳在锁屏、切出会话和休眠时调用 `Suspend`，恢复调用 `Resume`。钩子安装失败时以 1～30 秒退避重试。每 250ms 检查可交互输入桌面，安全桌面不可访问时清空代次并停止投递，不尝试越过系统限制。普通应用的密码框与普通按键无法通过此物理键接口区分；不希望任何按键参与可视化时应关闭菜单中的键盘监听。Windows 安全桌面和更高完整性应用的输入可能不可用，这不是错误绕过目标。

真实 Windows 验收仍须覆盖按住/松开、左右修饰键、Caps Lock、输入法、锁屏、UAC 安全桌面、长按时隐藏/切换及退出后钩子释放。合成测试不证明真实全局钩子已通过实机验证。
